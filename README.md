# woodcutter

Оптимальный одномерный раскрой (1D cutting stock) на Go.

## Какую задачу решает

Есть склад досок нескольких типов с ограниченными запасами и список требуемых
кусков нужной длины. Нужно нарезать куски из досок так, чтобы суммарная длина
использованного материала была минимальной.

Задача решается методом генерации столбцов Гилмора–Гомори:

1. LP-релаксация мастер-задачи (минимизация суммарной длины материала) даёт
   двойственные оценки.
2. Прайсинг через ограниченный рюкзак (bounded knapsack) порождает новые
   паттерны раскроя, пока это выгодно.
3. Целочисленная задача (ILP) на найденном пуле паттернов даёт итоговый план.

Между кусками закладывается фиксированный пропил (padding) 5 мм. LP- и
ILP-решатели (двухфазный симплекс + branch & bound) реализованы вручную, без
внешних зависимостей.

## Установка

Требуется Go 1.25+.

```sh
# Сборка бинарника в текущую директорию
go build -o woodcutter ./cmd/woodcutter

# Либо установка в $GOBIN / $GOPATH/bin
go install github.com/pkositsyn/woodcutter/cmd/woodcutter@latest
```

## Запуск

Программа читает задачу из stdin и печатает отчёт в stdout (диагностика —
в stderr):

```sh
./woodcutter < input.txt

# или без предварительной сборки
go run ./cmd/woodcutter < input.txt
```

Пример готовых входных файлов лежит в `internal/cutting/testdata/`:

```sh
go run ./cmd/woodcutter < internal/cutting/testdata/multi_type.txt
```

## Формат входного файла

Текстовый файл из двух секций, разделённых строкой `---`:

- **до `---`** — склад: доступные доски;
- **после `---`** — требования: нужные куски.

Каждая строка — это `длина, количество` (длина в мм). Разделителем внутри строки
может быть запятая или табуляция; количество можно опустить — тогда оно равно 1.
Пустые строки игнорируются. Требования с одинаковой длиной суммируются.

```
6000, 20
4000, 20
3000, 20
---
2500, 6
1800, 8
1200, 10
700, 12
```

Здесь на складе 20 досок по 6000 мм, 20 по 4000 мм и 20 по 3000 мм; требуется
нарезать 6 кусков по 2500 мм, 8 по 1800 мм, 10 по 1200 мм и 12 по 700 мм.

Требования длиннее самой длинной доски на складе отбрасываются (об этом пишется
в отчёте). Если запасов не хватает под спрос, задача признаётся недопустимой.
